# Read-path audit, 2026-11-05

Audit base: `3869907eb2a811c25dbde961fd04105460ccd2d9` on
`sprint/serialize-audit`. The scope is this landed base, its vendored format
2.0 standard, and IMPLEMENTING.md U1–U16. No dependency, wire format, public
API, or permissive reading is added. Source locations below refer to the audit
base unless stated otherwise.

The entry-point map was written before changing runtime code. "Bounded" means
the stated bound holds at this entry point, not that arbitrary caller code,
Lua metatables, or process resource exhaustion are made safe. A packet enters
through `ReadStream`; `BitReader` is the documented unchecked layer in
DESIGN.md (a), with trapping precondition checks and no refusal latch.

There are no signed fixed-width wire operations beyond the ranged int32,
int64 and int128 forms, no separate destination-capacity fixed reader, and no
JSON parser or JSON read surface in `src/`. JSON depth, duplicate keys, escapes,
and number parsing therefore have no entry point in this runtime. `wstring`
is absent. Public `bitsRequired*`, zig-zag and integer-carrier arithmetic helpers
do not parse a packet; the read path uses bounded integer `len`, `cmp`, `add`,
`sub` and shifts as mapped above. `copyString` is a trusted writer convenience,
not a read-time text repair.

## Failure and resource boundaries

Every scalar and value-string destination is assigned centrally only on
success. A 128-bit primitive can consume its low half before discovering that
the high half is missing, but returns no half-value and latches `past_end`.
Alignment and text validation can likewise consume bits before refusal. This
is permitted: STANDARD.md does not define a position after the failing read;
it requires all **later** reads to consume nothing. An object may retain earlier
successful fields, so callers discard a refused composite.

The runtime owns no wire-directed recursion. A schema's own object callback,
recursive shape, collection loop and maximum packet size remain caller
responsibilities. For an n-byte supplied packet, the bit reader holds the
original immutable string plus one n+16-byte padded copy. Returned payloads
are no larger than the remaining packet, and a string's prefix also limits
its payload to the declared buffer size minus one. The UTF-8 scan is linear
in that bounded payload. No claimed length alone allocates its claimed size.
This audit does not claim survival under arbitrary process-wide out-of-memory
conditions or strings approaching the signed 64-bit address-space limit.

Compressed floats are checked against their quantized integer maximum and
finite result, not incorrectly clamped to the declaration's `max`: the standard
allows the float32 top decode to exceed `max` through delta rounding. Negative
zero and subnormals in raw float/double fields remain valid. No tolerance or
repair path was added.

## Findings

### sra-lua-1 — width addition can bypass fixed declaration refusal

- **Location:** `src/serialize_fixed.lua:79` and `:80`.
- **Input and effect:** caller-controlled positive integer widths can overflow
  `integerBits + fractionBits` to a negative Lua integer. The `total > 64`
  check then accepts the declaration and the read selects its 64-bit arm.
  Depending on the fraction width it consumes a smaller field or accepts a
  zero-bit value. A packet cannot change a valid fixed declaration on its own;
  the exposure requires a malformed caller/schema declaration.
- **Severity:** low; declaration integrity and U7/U16 refusal failure, with no
  memory overwrite or ordinary-valid-schema crash established.
- **Reduction:** reject `integerBits > 128` and `fractionBits > 127` before
  forming their sum. Existing lower bounds, supported-total check, capacity
  check and refusal spelling remain unchanged. This removes overflow from
  the declaration domain without changing valid encodings.
- **Pin:** `test/uniform/uniform_test.lua:291`,
  `TestU16FixedWidthsCannotWrap`, checks refusal before bits move, unchanged
  destination, terminality, reset, the Q1.127 and Q128.0 legal edges, and the
  existing write/measure misuse mechanism. The existing fuzz harness's
  `fuzz/differential_test.go:1169`, `TestAuditFixedWidthRefusalSeeds`, carries
  24 deterministic seeds: six invalid declarations across empty, zero,
  all-set and 16-byte zero packets. Both pins fail on the audit base.
- **Status:** fixed by `b3258f759c9abf8a25861a387ad8f5d3780de3be`.
